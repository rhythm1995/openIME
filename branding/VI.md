# openIME 品牌视觉规范（VI）

> openIME 的视觉识别系统。所有产品界面、官网、物料均以此为唯一基准。
> 2026-08 起，应用与官网统一采用 **Raycast 设计语言**（近黑画布 + 键帽质感 + 强制深色）。

---

## 1. 品牌核心理念

| 维度 | 内容 |
|---|---|
| **产品** | 开源、跨平台、本地优先的语音输入法 |
| **核心动作** | 说话即输入 —— 声音转化为文字 |
| **品牌承诺** | 精确、克制、值得信赖的工具 |
| **气质** | 开发者工具气质（Raycast 式深色驾驶舱，非消费级应用的活泼亲切） |
| **隐喻** | 声波 / 语音波形 |

## 3. 色彩系统（强制深色 · Raycast 阶梯）

应用与官网**统一强制深色**，无浅色主题。全系统约 98% 无彩色，粒蓝是唯一品牌强调。

### 3.1 表面阶梯

| 层级 | Token | 色值 | 用途 |
|---|---|---|---|
| Canvas 画布 | `--bg` | `#040506` | 页面唯一背景 |
| Card 卡片 | `--card-bg` | `#07080a` | 卡片、浮层基底 |
| Recessed 凹陷 | `--recessed` | `#111214` | 输入框、聊天气泡、凹陷容器 |
| Badge 密集标签 | `--badge-bg` | `#1b1c1e` | 状态标签底、开关 off 态、toast |

### 3.2 文字

| 角色 | 色值 | 用途 |
|---|---|---|
| 主文字 | `#ffffff` | 标题、强调 |
| 次文字 | `#9c9c9d` | 正文、说明 |
| 三级文字 | `#6a6b6c` | 仅限辅助提示与 mono 元数据（对比度 4.6:1，不用于 14px 以下正文长文） |

### 3.3 边框

| 角色 | 色值 | 用途 |
|---|---|---|
| 边框 | `#363739` | 卡片外环、控件边框 |
| 弱分隔 | `#1b1c1e` | 列表行分隔、卡片内部分割 |

### 3.4 品牌主色（粒蓝）

**粒蓝 `#5C6AFF`** —— 唯一品牌强调色。角色纪律：

| 允许 | 禁止 |
|---|---|
| 主 CTA 按钮填充 | 大面积背景 |
| 选中态（导航 active、单选选中、switch on） | 正文链接色滥用 |
| 波形 / 声波图形 | 图标通用色 |
| 录音/下载进度 | 装饰渐变 |

- hover：`#4452ED`；soft 背景：`rgba(92,106,255,0.16)`

### 3.5 功能色（语义）

| 角色 | 色值 |
|---|---|
| 成功 success | `#59d499` |
| 警告 warning | `#ff9500` |
| 危险 danger | `#ff453a`（overlay 录音点沿用红 `#ff453a`） |

## 4. 字体系统

```
主字体栈：-apple-system, "SF Pro Text", "PingFang SC", "Helvetica Neue", system-ui, sans-serif
等宽（技术元数据专用）：ui-monospace, SFMono-Regular, "SF Mono", Menlo, monospace
```

- 系统字体，不引入外部字体 —— 零加载延迟
- **等宽只用于技术元数据**：时间戳、热词权重、模型规格（大小/ID）、版本号 —— 让技术数据"像被工程标定过"
- 官网（website/）拉丁字符使用 Inter（Google Fonts），中文自动回退本栈

## 5. 图形语言（Raycast 键帽体系）

### 5.1 深度：键帽内阴影（signature）

所有卡片与浮层**不用外投影**，统一键帽内阴影栈：

```css
--key-shadow:
  rgba(255,255,255,0.05) 0 1px 0 0 inset,   /* 顶部内侧高光 */
  rgba(255,255,255,0.25) 0 0 0 1px,          /* 1px 外环 */
  rgba(0,0,0,0.2) 0 -1px 0 0 inset;          /* 底部内侧暗影 */
```

浮层（modal / 菜单 / toast）在键帽环外加 `0 12px 40px rgba(0,0,0,0.5)` 大暗影。

### 5.2 圆角

| 元素 | 值 |
|---|---|
| 卡片 | `16px` |
| 按钮 / 输入 / 下拉 | `8px` |
| Badge | `6px` |
| 胶囊（overlay / toast） | `999px` |

### 5.3 控件

- 控件高度：`--control-h: 36px`
- 开关 on 态 = 粒蓝；off 态 = badge 底 + 白色内环
- 输入框 = recessed 凹陷填充（"可以打字的井"），focus 边框粒蓝

### 5.4 毛玻璃

侧栏 `backdrop-filter: blur(30px) saturate(180%)`，底色 `rgba(7,8,10,0.72)`。

### 5.5 图标

lucide-react，线条 `strokeWidth: 2`，与文字基线对齐。

## 6. 设计原则

1. **克制**：98% 无彩色。粒蓝稀有点缀，无发光、无装饰渐变（官网 hero 艺术除外，那是唯一的"影院时刻"）。
2. **精确**：几何对齐，间距统一（8 的倍数体系）。
3. **键帽质感**：深度来自 inset 高光/暗影与 1px 外环，而非外投影。
4. **工具感**：Raycast 式驾驶舱气质；技术数据用等宽字体呈现。
5. **强制深色**：应用无浅色主题；窗口 `theme: Dark`，`color-scheme: dark`。
6. **缩放性**：所有图形在小尺寸（16px）下必须可辨认。

## 7. 官网同源（website/）

官网与应用共用本规范：同一表面阶梯、同一粒蓝角色、同一键帽阴影栈。
