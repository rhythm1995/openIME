# openIME 用户指南

面向最终用户。开发者文档见 [development.md](./development.md)，排障见 [troubleshooting.md](./troubleshooting.md)。

---

## 安装（macOS）

1. 从 [Releases](../releases) 下载 `.dmg`，把 openIME 拖进 `/Applications`。
2. 首次打开：**右键 → 打开**（内测包未公证）。
3. 进入 **设置 → 系统权限**，授权 **麦克风** 与 **辅助功能**。

> 同一签名重装一般不必重新授权；若失效见 [troubleshooting.md](./troubleshooting.md)。

---

## 把语音变成文字（核心用法）

1. 确保引擎已配置（见下节）。所有设置**即改即存**，无需点保存按钮。
2. 把光标点到任意可输入位置（文档、聊天框、搜索栏……）。
3. 按 **Fn（🌐 键）** 开始说话，再按一次停止。
4. 识别结果会**逐字输入到光标处**，录音结束后可能再被 AI 润色一次。

## 选择识别引擎

设置 → 识别引擎：

| 引擎 | 何时用 |
|---|---|
| **本地 sherpa-onnx**（推荐） | 注重隐私 / 离线；首次需点「下载」装模型 |
| **百炼 WebSocket 流式** | 云端逐字上屏，需 API Key |
| **OpenAI 兼容 REST** | 兼容 Whisper / OpenRouter 等 |
| **Multimodal REST** | 百炼 Qwen3 ASR 非流式 |

云端档填控制台地址即可，应用自动归一为正确端点。

## AI 润色

设置 → AI 润色，三档：

- **保持原样**：仅本地规则清理（去口头禅、补标点、纠同音字）。
- **中度**：规则 + LLM 仅校对（修 ASR 错，不改措辞）。
- **高度**：LLM 改写润色；可选**风格包**（自定义 system prompt，F1 快捷键切换）。

本地润色用 Qwen3.5 小模型，设置页可一键下载三档（0.8B / 2B / 4B，按机型推荐）。策略：本地模型优先，未下载或失败自动回退云端，双失败则原文直出（不报错）。

## 语音翻译

设置 → 翻译：配置 **翻译快捷键**、**目标语言**与「先润色再翻译」。目标语言按后端分档：纯本地润色模型兼译时为基础 7 语（中 / 英 / 日 / 韩 / 法 / 德 / 西）；启用云端或本地专翻小模型（MiLMMT-46 / HY-MT）后解锁扩展集（含繁中 / 粤语 / 阿拉伯 / 俄等约 20 种）。按翻译快捷键说源语言，停止后目标语言直接插入光标处。云端走云凭据；本地专翻可离线，弱机可用润色模型兼译。

---

## 前缀角色（进阶）

设置 → 角色 / 风格包：给风格包配置**前缀**（如「邮件:」「翻译:」）后，听写结果以该前缀开头时自动按对应角色处理（换 system prompt / 模型）。开启后听写改为整段上屏（不再逐字流式）。

---

## 插入兼容性（粘贴兜底）

设置 → 插入与剪贴板：默认**自动**（先模拟按键逐字输入，失败自动改粘贴）；远程桌面等吞模拟按键的 App 可加进**粘贴兜底列表**，或选「只粘贴」。粘贴后约 0.75 秒自动恢复你原来复制的剪贴板内容。

---

## 文件转字幕

设置 → 文件转录 → **选择音频文件转录** → 生成文本 + **导出 SRT 字幕**。长音频自动分段转写（分段时长 / 重叠可调，默认 60 秒 / 4 秒），显示进度并可随时取消。

---

## 快捷键

设置分为两组侧边栏入口：**语音配置**（快捷键与触发、识别引擎、音频、文件转录、插入兼容性、应用行为、权限、功能测试）与 **AI 增强配置**（润色、角色 / 风格包、翻译）。快捷键相关设置在 语音配置 → 快捷键：

- **录音快捷键**：默认 `Fn`，可改组合键（如 `Alt+Shift+D`）。
- **触发模式**：默认 **按住说话**（PTT，松开停），可切换为「切换」（按一次开 / 再按停）。
- **风格包切换**：可选，如 `Ctrl+Shift+P`。
- **翻译快捷键**：可选，如 `Alt+Shift+T`；按下说源语言，光标处插入目标语言。

> 用 Fn 键需在 **系统设置 → 键盘 →「按下 🌐 键时」** 选「不执行任何操作」，否则系统会拦截。

> 按住说话模式下，按住 Fn 超过「短按阈值」（默认 300 毫秒，可调）才开始录音；提前松开视为误触，自动补发 🌐 键原功能（仅 macOS）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 按 Fn 没反应 | 确认引擎已配置（设置即改即存）；确认权限已授权；Fn 被拦截则改组合键 |
| 识别不准 | 加热词；选更准的引擎 / 模型；开启 AI 润色 |
| 授权反复失效 | 用 `./scripts/build.sh install` 重装（固定签名），见 [troubleshooting.md](./troubleshooting.md) |
| 麦克风无声 | 设置 → 音频，换设备并点「测试」 |

更多排障与日志位置见 [troubleshooting.md](./troubleshooting.md)。
